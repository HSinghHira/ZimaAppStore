# ZimaOS / CasaOS Community App Store

A Community app store for [ZimaOS](https://www.zimaspace.com/ZimaOS) and [CasaOS](https://casaos.io/), maintained by [HSinghHira](https://github.com/HSinghHira).

---

## 🟢 ZimaOS

ZimaOS reads app stores from a `store.json` manifest.

1. Open the **ZimaOS** dashboard.
2. Go to **App Store** → click the **⚙️ Community store**.
3. Click ➕ **Icon**.
4. Paste below URL:

   ```
   https://ZimaOS.HSinghHira.me/store.json
   ```

5. **Add**, then refresh the App Store page.

> 💡 If the store doesn't show up right away, try refreshing or restarting the App Store service — ZimaOS occasionally caches store sources.

---

## 🟠 CasaOS

CasaOS doesn't read `store.json` — instead, it can install a full custom app store from a **zip archive**.

1. Open the **CasaOS** dashboard.
2. Go to **App Store**.
3. Click on **+ Add Source**.
4. Paste in the store archive URL:

   ```
   https://ZimaOS.HSinghHira.me/latest.zip
   ```

5. Confirm **Add**.

> 💡 `latest.zip` always points to the most recent build — no need to update the link when new apps are added.
